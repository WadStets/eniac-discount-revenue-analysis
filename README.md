# Data-cleaning-and-presentation
Discount &amp; Revenue Analysis.
This study project analyzes discount behavior and its impact on revenue and product categories.
Focused on data cleaning and data analysis using Python.

### Project Objectives


1 Clean and standardize multiple raw datasets

2 Identify and resolve data quality issues

3 Build a consolidated master dataset

4 Analyze discount structure and discount intensity

5 Support data-driven pricing and margin decisions


### Programming Language

Python
