# Eniac Discount & Revenue Analysis

Study project analyzing discount behavior and its impact on revenue and product categories for a retail dataset (Eniac). The project covers data cleaning, exploratory data analysis (EDA), and discount-intensity analysis to support data-driven pricing and margin decisions.

## Project Objectives

1. Clean and standardize multiple raw datasets
2. Identify and resolve data quality issues
3. Build a consolidated master dataset
4. Analyze discount structure and discount intensity
5. Support data-driven pricing and margin decisions

## Tech Stack

**Language:** Python

**Data Analysis & Processing:** Pandas, NumPy

**Visualization:** Matplotlib, Seaborn

**Tools & Environment:** Jupyter Notebook, Git, GitHub

## How to Run

1. Clone the repository:

git clone https://github.com/WadStets/eniac-discount-revenue-analysis.git

2. Install dependencies:

pip install pandas numpy matplotlib seaborn jupyter

3. Open the notebook:

jupyter notebook eniac_disc_analysis.ipynb
